# 🌍 همگام‌سازی منطقه زمانی IP

[🇬🇧 English](README.md)

**IP Timezone Sync** افزونه‌ای برای مرورگرهای مبتنی بر Chromium است که کمک می‌کند منطقه زمانی‌ای که وب‌سایت‌ها از مرورگر شما دریافت می‌کنند، با منطقه زمانی IP اینترنتتان هماهنگ‌تر باشد.

## 🤔 این افزونه چه کاری انجام می‌دهد؟

فرض کنید با VPN یا پراکسی به اینترنت وصل شده‌اید و IP شما مربوط به کشور دیگری است؛ اما منطقه زمانی مرورگرتان هنوز روی زمان محل واقعی دستگاه تنظیم شده است. در این شرایط ممکن است بعضی وب‌سایت‌ها اطلاعات زمانی متفاوتی از شما دریافت کنند.

این افزونه منطقه زمانی تقریبی IP شما را تشخیص می‌دهد و تلاش می‌کند اطلاعات تاریخ و ساعت قابل مشاهده برای وب‌سایت‌ها را با آن هماهنگ کند.

برای مثال، اگر IP شما مربوط به سوئد باشد، افزونه تلاش می‌کند وب‌سایت‌ها منطقه زمانی مرتبط با سوئد را مشاهده کنند.

> 💡 **نکته:** افزونه ساعت ویندوز یا تنظیمات اصلی مرورگر را تغییر نمی‌دهد. میزان هماهنگی به وب‌سایت و سطح انتخابی شما بستگی دارد و هماهنگی کامل یا نامرئی‌ماندن در برابر ابزارهای تشخیص را تضمین نمی‌کند.

## ✨ امکانات

- 🌐 تشخیص خودکار منطقه زمانی بر اساس IP اینترنت
- 🔄 امکان بررسی دوباره IP در هر زمان
- ⏱️ بررسی خودکار هنگام اجرای مرورگر یا باز شدن تب جدید
- 🕐 امکان بررسی دوره‌ای هر یک یا شش ساعت
- 🎚️ چهار سطح عملکرد، از حالت سبک تا هماهنگی گسترده‌تر
- ⚡ توجه به مصرف منابع و جلوگیری از پردازش غیرضروری
- 🧭 سازگار با مرورگرهای مبتنی بر Chromium که از افزونه‌های Manifest V3 پشتیبانی می‌کنند؛ مانند Chrome، Microsoft Edge، Brave، Opera و Vivaldi. این‌ها فقط چند نمونه‌اند و فهرست مرورگرهای پشتیبانی‌شده به این موارد محدود نیست.

## 🎚️ کدام سطح را انتخاب کنم؟

چهار سطح در اختیار دارید. هرچه سطح بالاتر باشد، افزونه بخش‌های بیشتری از رفتار تاریخ و ساعت وب‌سایت‌ها را هماهنگ می‌کند؛ البته ممکن است مصرف منابع بیشتر شود یا بعضی سایت‌ها با آن سازگار نباشند.

- **سطح ۱ — سبک (پیش‌فرض):** کم‌مصرف‌ترین حالت و بهترین گزینه برای شروع و استفاده روزمره.
- **سطح ۲ — هماهنگی بیشتر:** علاوه بر حالت اول، بخش‌های بیشتری از نمایش تاریخ و ساعت را هماهنگ می‌کند.
- **سطح ۳ — پیشرفته:** هماهنگی گسترده‌تری برای سایت‌هایی که هنوز اختلاف زمانی دارند.
- **سطح ۴ — حداکثری:** بیشترین میزان هماهنگی؛ ممکن است مصرف منابع یا احتمال ناسازگاری بیشتر شود.

> ✅ **پیشنهاد:** ابتدا سطح ۱ را امتحان کنید. اگر در سایت موردنظرتان هنوز اختلاف زمانی وجود داشت، سطح‌های بالاتر را یکی‌یکی تست کنید. لازم نیست همیشه سطح ۴ فعال باشد.

## 📥 نصب افزونه

در حال حاضر می‌توانید افزونه را به‌صورت دستی نصب کنید:

1. از [صفحه پروژه در GitHub](https://github.com/web-elite/ip-timezone-sync) فایل ZIP را دریافت و از حالت فشرده خارج کنید.
2. صفحه مدیریت افزونه‌های مرورگرتان را باز کنید. برای نمونه:
   - Chrome و Brave: آدرس `chrome://extensions`
   - Microsoft Edge: آدرس `edge://extensions`
   - در سایر مرورگرهای مبتنی بر Chromium، صفحه مدیریت افزونه‌ها را باز کنید.
3. گزینه **Developer mode** یا «حالت توسعه‌دهنده» را روشن کنید.
4. روی **Load unpacked** یا «بارگذاری بسته‌بندی‌نشده» بزنید و پوشه‌ای را که از ZIP خارج کرده‌اید انتخاب کنید.
5. پس از نصب، وارد تنظیمات افزونه شوید و سطح عملکرد و زمان بررسی IP را انتخاب کنید.

## ⚙️ چطور از افزونه استفاده کنم؟

بعد از نصب، از بخش تنظیمات می‌توانید زمان بررسی IP را مشخص کنید:

- **New tab:** با باز شدن تب جدید، IP بررسی می‌شود.
- **Browser startup:** هنگام اجرای مرورگر بررسی انجام می‌شود.
- **Every 1 hour / 6 hours:** هر یک یا شش ساعت یک‌بار بررسی انجام می‌شود.
- **Manual only:** بررسی خودکار انجام نمی‌شود؛ هر زمان خواستید روی **Check IP now** بزنید.

برای ذخیره تغییرات روی **Save settings** کلیک کنید. اگر سطح عملکرد را تغییر دهید، تب‌های باز دوباره بارگذاری می‌شوند تا تنظیم جدید روی آن‌ها اعمال شود.

## 🔐 حریم خصوصی و نکات مهم

- برای تشخیص منطقه زمانی، افزونه از سرویس‌های [ipwho.is](https://ipwho.is/) و در صورت نیاز [ipapi.co](https://ipapi.co/) استفاده می‌کند. این سرویس‌ها IP عمومی‌ای را که درخواست از طریق آن ارسال شده دریافت می‌کنند.
- تشخیص منطقه زمانی بر اساس IP تقریبی است و لزوماً موقعیت واقعی شما را نشان نمی‌دهد.
- اگر از VPN یا پراکسی استفاده می‌کنید، نتیجه به IPای بستگی دارد که سرویس تشخیص مشاهده می‌کند. بعضی پراکسی‌هایی که فقط داخل برنامه‌های دیگر تنظیم شده‌اند، ممکن است روی درخواست افزونه اثر نگذارند.
- افزونه ساعت و منطقه زمانی تنظیم‌شده در ویندوز یا سیستم‌عامل را تغییر نمی‌دهد.
- بعضی وب‌سایت‌ها ممکن است همچنان منطقه زمانی اصلی دستگاه را تشخیص دهند یا به روش دیگری زمان را بررسی کنند.
- سطح‌های بالاتر ممکن است با برخی سایت‌ها سازگار نباشند. اگر سایتی درست کار نکرد، سطح را پایین بیاورید یا به سطح ۱ برگردید.
- این افزونه ابزار ناشناس‌ماندن یا تضمین عبور از سیستم‌های تشخیص هویت و اثرانگشت مرورگر نیست.
