Important limitations

  • The IP lookup runs from the extension service worker and normally follows Chromium's configured proxy or system VPN route. A proxy configured only inside another application may not affect browser traffic.
  • IP geolocation is approximate. Countries with multiple timezones may require a location-aware provider; the returned timezone is the provider's best estimate for the public IP.
  • Level 1 changes the default timezone used by Intl.DateTimeFormat only; native Date behavior remains tied to the browser timezone. Higher levels progressively add local Date getters, setters, and constructor/parsing behavior.
  • These JavaScript API overrides are compatibility shims, not an operating-system timezone change. Workers, service workers, browser internals, and fingerprinting techniques may reveal inconsistencies.
  • Websites may explicitly request a timezone in Intl options; explicit website-supplied timezones are preserved.
  • IP lookup is sent to ipwho.is, with ipapi.co as fallback. These providers receive the public IP used for the request.
